Set up Gift Search

Open the dashboard and turn on Demo mode to watch the agents work. The browser demos run without an account or API key.

Quick start

  1. Install Node.js 22.20 or later with npm.
  2. Clone the repository and start the app in a terminal on macOS, Linux, or WSL. If you already have a copy, run the last line from its folder. 
    git clone https://github.com/sriaradhyula/gift-search-agent-skill.git
cd gift-search-agent-skill
./runme.sh --demo
  3. In the dashboard, turn on Demo mode, pick a scenario, and select Run demo.

If the browser stays closed, open the address printed in the terminal. Press Ctrl+C to stop the app.

Run a live search

  1. Install Claude Code and sign in with claude auth login.
  2. Stop the demo with Ctrl+C and run ./runme.sh.
  3. Fill in the gift brief and select Find gifts.

Claude Code can search the web. To add Google Shopping results, save your SerpApi key in ~/.config/serpapi.txt.

Use Run with to switch agents. Setup for Codex, Cursor, OpenCode, and CAIPE

Install the skill

To use Gift Search inside your agent, choose the agent and run the command from your project.

npx skills add sriaradhyula/gift-search-agent-skill --skill gift-search -a codex

Start a new agent session after installing. Install from a local copy or for all projects

Try it in Claude Code

/gift-search Find a gift for my sister who loves coffee. Budget $75 USD, shipping to the United States.

Example run

Open the chocolate demo and select Run demo. Read Research memory to see how the second round uses the first reviewer’s feedback. Use Copy demo link to share any scenario.

To see a saved report, download the example JSON and open it with Import results.

How the agents work

  1. Scout. Two searches look for gifts tied to the recipient’s interests and adjacent ideas that suit the occasion.
  2. Verify. A reviewer checks the retailer pages for the product, price, availability, and delivery region.
  3. Rank. The shortlist favors recipient fit and reliable listings. Each card includes a reason and a practical caveat.

For a local install, pull the repository and rerun the install command. For a GitHub install, run the command below.

npx skills update gift-search
