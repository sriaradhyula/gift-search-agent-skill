Gift Search skill

Give your agent a gift brief and get a ranked shortlist with reasons, prices, and retailer links when available.

Quick start

  1. Install Node.js 22.20 or later with npm. Use a terminal on macOS, Linux, or WSL. Download Node.js
  2. Clone the repository with Git and start the demo. You can also download it as a ZIP, unzip it, and run the last command from that folder. 
    git clone https://github.com/sriaradhyula/gift-search-agent-skill.git
cd gift-search-agent-skill
./runme.sh --demo
  3. Select Try a demo, choose a scenario, and select Run demo. If the browser stays closed, open the address printed in the terminal.

Switch to live search

  1. Stop the demo with Ctrl+C. For the default harness, install Claude Code and run claude auth login. Claude Code setup
  2. For Google Shopping discovery, save your SerpApi key as the only text in ~/.config/serpapi.txt. Create the folder if needed. Claude Code can use its web tools when a SerpApi key is unavailable. Manage your SerpApi key
  3. Run ./runme.sh, choose your harness under Run with, and select Find gifts.

If port 8000 is busy, run ./runme.sh --port 8001. Use --no-open to open the address manually and --help to see all options.

Install the skill

Choose your agent. Run the command from your project with Node.js 22.20 or later and Git access to the repository.

npx skills add sriaradhyula/gift-search-agent-skill --skill gift-search -a codex

Add --global to install for all of your projects. Start a new agent session after installing.

Install from a checkout

If you’re working from an authenticated local clone, run this from the project where you want the skill. Replace the path with your checkout’s absolute path.

npx skills add "/path/to/gift-search-agent-skill" --skill gift-search -a codex

Open from Claude Code

Start a Claude Code session on your computer and enter this prompt.

/gift-search Find a birthday gift for my sister. She likes coffee and slow mornings. Budget $75 USD, shipping to the United States.

Claude uses its own web tools to verify retailers and summarizes each scout’s contribution and the reviewer’s decisions. Ask Claude to open a dashboard when you want the brief and results in your browser.

To use Google Shopping for discovery, set SERPAPI_API_KEY or save the key in ~/.config/serpapi.txt. Use SERPAPI_API_KEY_FILE for a different path. Claude can also discover gifts through its web tools.

Example run

In a new agent session, ask for a shortlist and a dashboard export.

Use the gift-search skill to find a birthday gift for my sister. She loves coffee and slow mornings. I can spend up to $75 USD, shipping to the United States. Write a gift-report.json I can open in the dashboard.

The example dashboard starts with three Christmas gift ideas. Pick a recipient from the list or choose Someone else… to enter your own. Choose a suggested interest, type one, or select I’m not sure for a broader search. Select Surprise me to fill in a different Christmas brief. To view your agent’s search, select Import results and open its gift-report.json.

Select Try a demo, choose a coffee, outdoor, or creative gift scenario, then select Run demo. Watch the scouts share leads, the reviewer give feedback, and the team revise the shortlist over two turns. The demos use sample products and prices and run on GitHub Pages without credentials.

Select Share results to copy a gift list or Markdown checklist with retailer links, or download a PNG for sharing in a message.

Run the live dashboard locally

Use the launcher from the quick start and choose Claude Code, Codex, Cursor, OpenCode, or CAIPE under Run with. Claude Code is the default. Set 1–5 Research turns and select Find gifts.

Follow the animated graph as new scout personas take over each turn. In Research memory, scouts post public highlights and the reviewer records decisions and follow-ups. The next turn reads those notes. Use Search history to load a previous run and Continue search to add turns with the original brief and harness.

The results show how many Google Shopping leads SerpApi supplied. Research leads appears below the shortlist whenever there are leads that did not qualify. Each card shows what the retailer checks found.

Open Chat to ask the selected harness about the run or any other topic while research continues. Replies render as Markdown, and you can queue another message while the agent is answering.

Set GIFT_CLAUDE_CONSOLE=1 before starting the server to print activity in your terminal or tmux pane.

For OpenAI searches, set OPENAI_API_KEY, configure SerpApi as described above, and run npm run start:openai. Select Search Google Shopping and submit the brief. SerpApi finds products and OpenAI web search checks the retailer pages for price, stock, and shipping. Both providers can bill for API calls.

With only an OpenAI key, select Search live retailers to use web search for discovery and verification. The dashboard also falls back to web discovery if Google Shopping is unavailable or returns no candidates.

OpenAI searches default to gpt-5-mini. Set OPENAI_GIFT_MODEL to use a different reasoning model that supports Responses web search and structured output.

How the agents work

  1. Scout. Two searches look for gifts tied to the recipient’s interests and adjacent ideas that suit the occasion.
  2. Verify. A reviewer checks the retailer pages for the product, price, availability, and delivery region.
  3. Rank. The shortlist favors recipient fit and reliable listings. Each card includes a reason and a practical caveat.

The installed skill uses parallel delegation when your host and permissions support it. Other hosts run the roles as separate passes. Live listings require a web or shopping tool.

npx skills update gift-search
