How the agents collaborate

Gift Search turns a brief into a shortlist through parallel research, retailer verification, and a shared record of what the team learned.

A research turn

Recipient · Occasion · Budget · Destination

  1. Planner

    Uses the brief and shared memory to assign two or three scouts with distinct specialties.

  2. Scouts in parallel

    Search different angles, propose product links, and post highlights as they work.

  3. Retailer reviewer

    Checks the exact item, price, stock, and delivery coverage before it makes the shortlist.

Shared research memory

The next turn reads the leads, review decisions, and open questions. It creates new scouts and keeps the same reviewer.

One skill, two ways to run it

Install the skill in your agent and give it a brief. The host can delegate to scouts when it supports subagents, or run the research in separate passes.

In the dashboard, the server uses the same skill instructions and coordinates a planner, separate scout sessions, and a reviewer through the Agent Client Protocol (ACP). Pick Claude Code, Codex, Cursor, OpenCode, or CAIPE with Run with.

Discovery and verification

Claude Code can use web search. An optional SerpApi key adds Google Shopping leads. A managed worker can use Claude through LiteLLM and AgentCore Web Search over AWS PrivateLink.

The reviewer opens retailer pages and shipping policies to check the price, stock, and destination. The shortlist includes known shipping costs in the budget. Open Research leads to see why other items were left out.

Live memory and resumable runs

Scouts start each turn with the same memory snapshot. Their new posts stream to Research memory and go to the reviewer. The next turn’s planner uses those posts and review decisions to choose new assignments.

In the chocolate demo, the reviewer flags a sold-out $50 assortment. The next scouts look for a smaller box and find a $38 option with room in the budget for shipping.

Choose one to five turns per run. The dashboard saves a checkpoint after each completed turn, so Continue search can reuse the brief, shortlist, and prior research. Download memory.md to keep the notes.
